flotek sentinel

This page is the live showcase. Reachability, the full DNS list, mail records, the certificate and domain registration are checked when you add a site. WordPress backups run in the server build after approval.

Team

Only an administrator can add people. Roles are Administrator, Operator and Viewer. This review copy stores the team in this browser.

How to show it

1. Sign in as Flotek.

2. Press “Check flotek.io”, or type a customer domain and press “Add and check”.

3. Open the site. Show Reach, then DNS. That table is the full record list, not a sample.

4. Open Certificate and Registration so they can see the expiry and the registrar.

5. Open Team and add a user with a role. Viewers cannot add sites.

After they approve it, this same product moves to a Flotek subdomain. That copy keeps the accounts on the server and adds WordPress backups and file recovery.
