Websites

A website is a page we open and, for WordPress, a site we can change. The list is saved in this browser. Download a copy before you switch computers, or it will not be there.

Domains

A domain is the name only: DNS, mail, certificate and registration. It is not a website and it has no WordPress users.

Incidents

Open problems are grouped by website and by domain. Acknowledge one when it is dealt with. It moves into the archive for that same website or domain.

Team

Only an administrator can add people. Roles are Administrator, Operator and Viewer.
